# S5 — MVCC, vacuum, bloat e HOT updates

- **Suite:** `tests/p_05.spec.ts` · **Tag:** `s05` · **Status:** pendente

## O que fazer

Manter a tabela saudável sob updates frequentes de `status`: medir dead tuples,
avaliar `fillfactor`/HOT updates e a dependência do autovacuum.

## Query alvo

```sql
UPDATE job SET status = 'succeeded', updated_at = now() WHERE id = $1;
```

## Critério de aceite

Dead tuples e bloat medidos antes/depois de `VACUUM`; updates que não mudam
coluna indexada viram HOT.
