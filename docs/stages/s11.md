- **Suite:** `tests/p_11.spec.ts` · **Tag:** `s11` · **Status:** pendente

## O que fazer

Consumir sem prefetch e depois com `prefetch(N)`; `noAck:false` com
`ack`/`nack`. Prefetch é o **backpressure** do consumidor.

## Query alvo

Sem SQL de leitura — o alvo é o consumo AMQP sob carga.

## Critério de aceite

Sem prefetch, `unacked`/memória sobem; com prefetch, estável.
