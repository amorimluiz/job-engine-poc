# S1 — Modelagem e seed

- **Suite:** `tests/p_01.spec.ts` · **Tag:** `s01` · **Status:** concluído

## O que implementar no motor

- **Models (MSC):** `pipeline.model.ts`, `job.model.ts`, `execution.model.ts`.
- **Seed:** `scripts/seed.ts` — 340k pipelines (payload = linha NYC 311) e
  **3 jobs por pipeline** (`normalize`, `enrich`, `classify`) = 1,02M jobs.
- **Sem controller/service ainda** — nada executa job nesta etapa.
- **Objetivo:** schema com FK e **sem índice secundário**, para sentir o custo
  sem índice. (No Postgres, FK não cria índice.)

## Queries possíveis

```sql
SELECT * FROM job WHERE pipeline_id = $1;

SELECT * FROM job WHERE status = 'pending' AND run_at <= now()
ORDER BY run_at LIMIT 10;

SELECT * FROM execution WHERE job_id = $1 ORDER BY started_at DESC;

SELECT step, status FROM job WHERE pipeline_id = $1;
```

## Baseline × meta

| Query | Sem índice (medido) | Meta (pós S2) |
|---|---|---|
| `job WHERE pipeline_id` | ~23 ms | < 1 ms |
| claim `status='pending' ORDER BY run_at LIMIT 10` | ~59 ms | < 1 ms |
| `count(*) WHERE status='pending'` | ~42 ms | < 5 ms |
| `execution WHERE job_id` | 0,04 ms (vazio) | < 1 ms (cheio) |

## Critério de aceite

340k / 1,02M e as queries acima em **Seq Scan** (baseline).
