# S1 — Modelagem e seed

- **Suite:** `tests/p_01.spec.ts` · **Tag:** `s01` · **Status:** concluído

## O que fazer

Modelar `pipeline`/`job`/`execution` (com FK e **sem índice secundário**) e
popular volume real: 340.000 pipelines (payload = linha do CSV NYC 311) e 3 jobs
por pipeline. O objetivo é sentir o custo **sem índice** — no Postgres, uma FK
não cria índice sozinha.

## Queries alvo

```sql
SELECT * FROM job WHERE pipeline_id = $1;

SELECT * FROM job
WHERE status = 'pending' AND run_at <= now()
ORDER BY run_at LIMIT 10;

SELECT * FROM execution WHERE job_id = $1 ORDER BY started_at DESC;

SELECT step, status FROM job WHERE pipeline_id = $1;
```

## Critério de aceite

340k pipelines / 1,02M jobs e as queries acima em **Seq Scan** (baseline do S2).
