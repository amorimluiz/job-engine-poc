# S15 — Observabilidade

- **Suite:** `tests/p_15.spec.ts` · **Tag:** `s15` · **Status:** pendente

## O que fazer

Expor métricas de fila: profundidade por status, **idade do item mais antigo** e
lag do outbox; usar `pg_stat_statements` como painel.

## Queries alvo

```sql
SELECT status, count(*) FROM job GROUP BY status;

SELECT min(run_at) FROM job WHERE status = 'pending';

SELECT count(*) FROM outbox WHERE sent_at IS NULL;
```

## Critério de aceite

`/metrics` expõe as métricas; a fila drena e a idade não cresce sem limite.
