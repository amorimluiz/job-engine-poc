# S18 — Capstone: escala e isolamento

- **Suite:** `tests/p_18.spec.ts` · **Tag:** `s18` · **Status:** pendente

## O que fazer

Medir N réplicas do worker com `SKIP LOCKED`, usar advisory lock para tarefa
singleton e decidir com dados sobre banco dedicado.

## Query alvo

```sql
-- mesma fatia de pendentes do S7, agora disputada por N réplicas
SELECT id FROM job
WHERE status = 'pending' AND run_at <= now()
ORDER BY run_at LIMIT $1;
```

## Critério de aceite

Throughput escala com réplicas sem duplicar/perder; números para decidir
isolamento.
