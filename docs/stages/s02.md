# S2 — Índices + EXPLAIN

- **Suite:** `tests/p_02.spec.ts` · **Tag:** `s02` · **Status:** pendente

## O que fazer

Indexar as queries quentes do S1 e **provar** a mudança de plano com
`EXPLAIN (ANALYZE, BUFFERS)` e `pg_stat_statements`. Avaliar quando o planner
ainda prefere Seq Scan.

## Queries alvo

```sql
SELECT * FROM job WHERE pipeline_id = $1;

SELECT * FROM job WHERE pipeline_id = $1 AND status = 'pending';

SELECT * FROM job
WHERE status = 'pending' AND run_at <= now()
ORDER BY run_at LIMIT 10;

SELECT * FROM execution WHERE job_id = $1 ORDER BY started_at DESC;
```

## Critério de aceite

Seq Scan → Index Scan / Index Only / Bitmap e queda de `total_exec_time`.
