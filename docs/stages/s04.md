# S4 — N+1 e O(n²)

- **Suite:** `tests/p_04.spec.ts` · **Tag:** `s04` · **Status:** pendente

## O que fazer

Eliminar leitura N+1 e custo quadrático: buscar execuções em lote, paginar por
cursor e trocar o recálculo de agregado por contador incremental.

## Queries alvo

```sql
-- N+1: uma query por job
SELECT * FROM execution WHERE job_id = $1;

-- paginação por offset (custo cresce com o volume)
SELECT * FROM job ORDER BY id LIMIT 50 OFFSET 1000000;

-- recálculo do total a cada evento (custo quadrático)
SELECT sum(...) FROM execution WHERE pipeline_id = $1;
```

## Critério de aceite

Número de queries por job **constante** conforme o histórico cresce; paginação
estável em volume.
