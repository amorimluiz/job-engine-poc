# S4 — N+1 e O(n²)

- **Suite:** `tests/p_04.spec.ts` · **Tag:** `s04` · **Status:** pendente

## O que implementar no motor

- **Service:** `jobs.service.ts` — trocar leitura por item por **busca em lote**
  (`ANY`/`JOIN`), paginação por **cursor** e **contador incremental** no lugar
  de recalcular agregado.
- **Controller:** `jobs.controller.ts` — listagem com cursor.
- **Para:** o custo por job não crescer com o histórico.

## Queries possíveis

```sql
-- N+1: uma query por job
SELECT * FROM execution WHERE job_id = $1;

-- paginação por offset
SELECT * FROM job ORDER BY id LIMIT 50 OFFSET 1000000;

-- recálculo do total a cada evento
SELECT sum(...) FROM execution WHERE pipeline_id = $1;
```

## Baseline × meta

| Item | Baseline | Meta pós-otimização |
|---|---|---|
| queries por job | cresce com N (N+1) | **constante** (1 query/lote) |
| paginação | `OFFSET` cresce com o volume | cursor estável |
| agregado | recalcula histórico | O(1) incremental |

## Critério de aceite

Número de queries por job constante; paginação estável em volume.
