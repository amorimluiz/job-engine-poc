- **Suite:** `tests/p_07.spec.ts` · **Tag:** `s07` · **Status:** pendente

- **Controller:** `jobs.controller.ts` — opcional (estado/administração).
- **Para:** o coração do motor — claim atômico + **lease** para recuperar job de
  worker morto, com 2 réplicas.

## Queries possíveis

```sql
-- seleção de pendentes (fatia disputada)
SELECT id FROM job
WHERE status = 'pending' AND run_at <= now()
ORDER BY run_at LIMIT $1
FOR UPDATE SKIP LOCKED;

-- transições condicionais do claim
UPDATE job SET status='running', locked_by=$1,
  locked_until = now() + interval '30 seconds'
WHERE id = ANY($2::bigint[]);

-- sweeper
UPDATE job SET status='pending', locked_by=NULL, locked_until=NULL
WHERE status='running' AND locked_until < now();
```
