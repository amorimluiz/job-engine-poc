# S7 — Fila no Postgres: SKIP LOCKED + lease

- **Suite:** `tests/p_07.spec.ts` · **Tag:** `s07` · **Status:** pendente

## O que fazer

Construir o **claim atômico** de um lote de jobs e o **lease** (recuperar job de
worker que morreu), rodando com 2 réplicas. Foco: nenhum job processado duas
vezes.

## Query alvo

```sql
-- fatia de pendentes que o claim disputa
SELECT id FROM job
WHERE status = 'pending' AND run_at <= now()
ORDER BY run_at
LIMIT $1;
```

## Critério de aceite

Nada processado duas vezes; job de worker morto recuperado após o lease vencer.
