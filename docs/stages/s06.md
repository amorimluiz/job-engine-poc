# S6 — Transações, locks e deadlocks

- **Suite:** `tests/p_06.spec.ts` · **Tag:** `s06` · **Status:** pendente

## O que fazer

Demonstrar `FOR UPDATE` (espera), `FOR UPDATE SKIP LOCKED` (não espera), um
deadlock intencional e um advisory lock para tarefa singleton.

## Queries alvo

```sql
SELECT * FROM job WHERE id = $1 FOR UPDATE;

SELECT * FROM job
WHERE status = 'pending' ORDER BY run_at LIMIT 1
FOR UPDATE SKIP LOCKED;

SELECT pg_try_advisory_lock(42);
```

## Critério de aceite

`SKIP LOCKED` não bloqueia; contenção visível em `pg_locks`; deadlock detectado.
